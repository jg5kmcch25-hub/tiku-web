# 题库答题网页

把题库文件拖进“文件夹”，自动生成答题页：

- 选择答案后，正确选项标绿；选错的话，错项标红、正确项同时标绿
- 点底部「继续」查看解析，再点一下进入下一题
- 全部答完后显示得分、正确率和错题回顾，还可以“再练错题”
- 答错的题自动收进**错题本**，随时可以单独拿出来再练、移出或清空
- 每个题库可以保存成一本“书”，在**书架**里按书本分类，随时回来接着练
- 导入时可以**新建一本书**，也可以**追加到已有的书**里，重复的题目会自动跳过
- **周测组卷**：点进来勾选一本或几本书，从勾选的书里随机抽题，单次最多 50 题
- **学习计时**：答题和看解析时自动计时，按每本书累计；首页用饼状图展示各本书的学习时长
- 右上角「主题」按钮可随时切换配色（粉色 / 薄荷 / 雾蓝 / 奶油 / 暗夜），选择会自动记住

## 使用方式

1. 双击打开 `index.html`（无需联网、无需安装任何软件）
2. 把题库文件（`.json` / `.csv` / `.txt`）拖进文件夹区域，或点击选择文件，也可以直接粘贴文本
3. 解析成功后给这本书起个名字，点「保存到书架并答题」，以后就能在书架里找到它
   - 下拉框里选「新建一本书」，或者选已有的书来追加新题目
4. 或者点「试试示例题库」直接体验

在书架里，每本书都有「开始答题」「追加题目」「删除」三个按钮：点「追加题目」再导入新文件，新题就会自动加进这本书。

首页上还可以勾选「打乱选项顺序」，每道题的选项会随机重排（正确答案会跟着变）。

书架和错题本的数据保存在浏览器的本地存储里，换浏览器或清除浏览器数据会清空，题库文件本身不受影响。

## 备份与恢复

首页下方有「💾 备份数据」和「📥 恢复备份」两个按钮：

- **备份数据**：把书架和错题本一起导出成一个 `.json` 备份文件，下载到电脑里
- **恢复备份**：选择之前导出的备份文件，书架和错题本就全部恢复回来

换电脑、换浏览器、或清除了浏览器数据之后，用备份文件一键就能找回所有记录。

## 题库格式

### JSON（推荐）

```json
{
  "questions": [
    {
      "question": "中国的首都是哪座城市？",
      "options": ["上海", "北京", "广州", "深圳"],
      "answer": "B",
      "explanation": "北京是中华人民共和国的首都。"
    }
  ]
}
```

`answer` 可以填字母（A/B/C/D），也可以填下标数字（0 = A）。

### TXT

```
题目：中国的首都是哪座城市？
A. 上海
B. 北京
C. 广州
D. 深圳
答案：B
解析：北京是中华人民共和国的首都。
```

每题之间空一行。

### CSV

表头固定为：

```
题干,选项A,选项B,选项C,选项D,答案,解析
```

## 文件说明

- `index.html` / `style.css` / `app.js` — 网页本体
- `sample-questions.json` — 示例题库，可参考它的格式制作自己的题库
